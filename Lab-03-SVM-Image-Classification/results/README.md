## Sample Results

### Original Color Images
![Original Color Images](./results/original-color-images.png) 

These are sample color images from the CIFAR-10 dataset. The selected classes for this lab were cats, dogs, and ships.

### Grayscale Images
![Grayscale Images](./results/grayscale-images.png)

The color images were converted to grayscale. This reduced each image to brightness values and made the data simpler for the SVM model.

### SVM Sample Predictions
![SVM Sample Predictions](./results/svm-sample-predictions.png)

This image shows sample predictions made by the SVM model. It helps compare the model’s predicted class with the correct class.

### SVM Model Comparison
![SVM Model Comparison](./results/svm-model-comparison.png)

This chart compares the accuracy of the Linear SVM and RBF SVM models. The RBF SVM performed better, with an accuracy of about 68.4%, while the Linear SVM reached about 54.7%.
